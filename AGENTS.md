# Next.js 16.2.4 App Router Project

## Project Overview
- **Framework**: Next.js 16.2.4 (latest version with App Router)
- **Runtime**: React 19.2.4
- **Styling**: Tailwind CSS 4 (with PostCSS plugin)
- **UI Components**: shadcn/ui + Radix UI
- **Language**: TypeScript 5
- **Icons**: Lucide React 1.11.0
- **Utilities**: clsx, tw-animate-css, tailwind-merge

## Architecture
- App Router structure (not Pages Router)
- Component-based architecture with shadcn/ui
- TypeScript for type safety
- Tailwind CSS v4 with utilities

## Important Notes
1. This is a modern Next.js 16 project with breaking changes from older versions — read `node_modules/next/dist/docs/` when unsure about APIs
2. Heed deprecation notices in the documentation
3. Use App Router patterns (server components by default)
4. Follow project coding style (camelCase, PascalCase for components, 4-space indentation)

## Common Commands
- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm run start` — Start production server
- `npm run lint` — Run ESLint

## Styling Conventions
- Use Tailwind CSS utility classes
- Use shadcn/ui components for UI elements
- Follow Tailwind CSS v4 syntax and patterns
